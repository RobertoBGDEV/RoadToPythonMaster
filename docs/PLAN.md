## Daily loop (1-2 h)
1. **Learn** one concept (5-10 min), editing and running every snippet.
2. **Solve** 2 new problems with a 25-minute timer. Write the complexity before you submit.
3. **Review** whatever the spaced-repetition queue shows (re-solve from scratch).
4. Weekly: one **Mock interview** and one system-design case aloud (45 min, whiteboard or paper).

## Rules that make it stick
- Never reveal a solution before a genuine 20-minute attempt; a peeked solution only earns reduced XP.
- After each problem write one line in Notes: *pattern + the trick*.
- Re-do problems you needed hints for. The queue handles it if you mark them solved honestly.
- In the last 2 weeks, stop learning new patterns: mix patterns randomly (Pattern drill + Mock).
